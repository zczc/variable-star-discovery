# 有标签的千星测试

本轮按用户 2026-11-12 的要求，先确定 1,000 颗的参考标签，再运行检测并直接对照。目标是 500 个周期变星和 500 个作者在所研究观测中未见变光的对照。旧 `scale-validation-v01` 是含未标注对象的诊断样本，不充当本轮有标准答案的测试集。

## 标签出处

Skarka et al. (2022), *Periodic variable A-F spectral type stars in the northern TESS continuous viewing zone*, A&A 666, A142。

- 论文 DOI：<https://doi.org/10.1051/0004-6361/202244037>
- 公开星表：<https://doi.org/10.26093/cds/vizier.36660142>
- 本地完整查询：`sources/north-harvard.txt`，来自 VizieR 的 Harvard 镜像，附有获取回执与 SHA-256。

作者逐颗检查光变、频谱、不同产品和像素资料。Table 5 是完整的 5,923 行研究样本，含 3,025 行有变光标签与 2,898 行空白类型、频率和变幅的非变光对象；不是只收录变星的目录。这里将空白类型映射成“作者未见变光”，依据是全文第 3、4 节的识别方法、Table 5 的完整样本范围及与全文人数的逐项核对，不能将这种空白映射推广到其他目录。

作者使用 TESS Cycle 2（Sector 14–26），优先采用 SPOC 2 分钟产品，并比较 30 分钟产品和 QLP。样本为北天连续观测区附近、V < 11 mag、温度约 6,000–10,000 K 的 A-F 星。非变光标签限于该观测和检测能力，不意味着永久没有任何变化。作者没有统一变幅下限，因此本次也不按运行后信号强弱删样本。

## 固定选样规则

- 正例类型限定为 DSCT、GDOR、两者的两种混合标记、ROTS、ROT、ROTM、EA、EB、EW、ELL。论文主频须在 0.125–20 次/天内，与当前程序 0.05–8 天搜索范围对应。物理类型不作为本次预测任务。
- 反例须为空白类型，并且没有论文表内的 VSX 记录。排除该表中已有的十个“作者未見变化但 VSX 已有记录”的冲突。
- 排除 VAR、类型歧义、重复 TIC 行、作者明确标注的污染对象及对应污染源系统。原表 5,923 行实际有 5,922 个不同 TIC；重复的 TIC 198456033 不纳入。
- 排除原项目已经使用的 1,153 个 TIC；名单记录在 `candidate-pool.json`。不读取新对象光变来选样。
- 要求 Sector 14–26 内有两个标准 SPOC 2 分钟光变，开始时间相隔至少 180 天，选最早和最晚时段。同一 TIC 只计一颗。
- 各标签内按 `SHA256("2026111201:<TIC>")` 排序取前 500 个，随后按另一个固定散列顺序运行。失败不换星；不足 500 个时程序报错，不能补未标注目标凑数。

## 主评分与周期评分分开

保留当前科学算法、搜索范围及阈值。本轮首先检验现有能力，不先修半周期代码。

**主预测：**既有结果中，SAP 或 PDCSAP 任一产品的 `periodic_detected` 跨时段判断为真，即记为检出重复信号。该字段与最后是否选定唯一周期不同；半周期或多周期疑点不会自动变成漏检。两种产品来自同一批观测，取任一支持是一项预先规定的输出规则，不是两次独立证据。

**次预测：**`selected_period_d` 是否非空，单独报告更严格的周期选择对正反例的保留情况。再将选定周期与论文主频的倒数比较；半倍、两倍等关系分别保存，不影响主评分，也不将论文主频的倒数一概称为轨道周期。

报告 TP、FN、FP、TN、不可用数、准确率、检出率、误报率及本平衡测试集的精确率；未完成或失败不能算 TN。多周期、弱信号等导致的漏检完整保留。按参考类型另列成绩，不能仅展示总数。来源算法的判断不充当参考答案，本轮不做首次发现查重。

`targets.json` 保存参考答案；`blind-inputs.json` 只保存 TIC 和数据地址，获取与检测工作进程不接收类型、主频、变幅或标签。全部预测保存后，由独立评分脚本读取标签作比较。

## 运行与复现

```sh
# 仅获取观测元数据，尚不读取光变
repo/.venv/bin/python repo/benchmarks/select_labelled_validation.py metadata
repo/.venv/bin/python repo/benchmarks/select_labelled_validation.py freeze
# 固定 protocol.json 中代码与名单的校验值，先提交再运行
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 repo/.venv/bin/python repo/benchmarks/run_labelled_validation.py
repo/.venv/bin/python repo/benchmarks/report_labelled_validation.py
```

原始 FITS 使用已有的直接公开 TESS 存储下载器，保存原始／压缩 SHA-256、ETag 与来源地址。只下载光变，不为这次直接标签对照重复下载全量像素。旧千星结果保留。新规则若使用本批结果调试，必须另存版本并将相应对象转入开发集。

## 排除过的数据来源

Audenaert et al. (2021), DOI `10.3847/1538-3881/ac166a`，第 3.8 节说明其 1,000 个恒定星光变由纯白噪声模拟，不能用于本轮真实反例。ASTRAFier（arXiv:2604.07437）第 4.2 节的 INSTRUMENT/JUNK 类混合仪器主导与缺乏变光的对象，也不是本轮所需的明确非变光标签。保存检索回执和相关短摘录，不把这两类替代真实非变光对照。
