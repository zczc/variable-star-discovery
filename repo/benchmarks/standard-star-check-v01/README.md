# 三颗标准星的实测检查（预先选样）

取 Marinoni 等 2016 年论文表 3 的前三颗 Pillar 对照星：G 191-B2B、GD 71、GD 153。论文第 5.1 节明确将它们作为常用基础光谱定标星的对照；第 4.3 节则说明长期密集监测计划已停止。另有每星至少三个夜晚、部分跨度六年以上的绝对测光，用于复查疑点，不等于持续覆盖所有周期。

本轮已阅读 [arXiv 全文](https://arxiv.org/html/1608.00759v1) 与 [原始 TeX](https://arxiv.org/src/1608.00759)，不仅是摘要。只核对 TeX 附带的表 3 节选和正文，未取得完整 CDS 表。三颗星的名字、坐标、波段、精度、幅度限制和逐星保留理由均写入 `protocol.json`。全文下载与哈希见 `paper-review.json`；第三方全文仅在本地缓存，仓库保存出处及核查摘要。

这三颗是有独立文献依据的**有条件对照**。原文的幅度 A 指半峰谷差；它的地面 B/V 波段与 TESS 不同。不能把表中数字直接当作 TESS 0.05–8 天范围内的排除上限。因此不计入正式真实安静星分母，不据此估计总体误报率。取每星最早、最晚两个受支持的非快速 SPOC 时段；缺数据不换星。检测只用冻结 v4，无论出现候选还是没有候选都保留；无候选不会反过来把这些星升级为已证明安静。
