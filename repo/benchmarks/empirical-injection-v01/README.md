# 实测残差注入 v01：分析前方案

先于残差拟合和检测结果冻结。两颗背景星 SZ Lyn 与 RS Boo 均已转为开发样本；新的 `independent-pilot-v02` 完全不参与。每颗使用原先选定的两个时段，保留 SAP/PDCSAP 的实测误差、相关结构、时间缺口与辅助通道。

用目录主周期和 12 阶傅里叶函数估计原有周期变化：拟合奇数圈来预测偶数圈，再反过来，只减去周期项。不丢弃异常点、不缩放残差、不重新随机生成噪声。残差仍可能含恒星的其他变化、调制、趋势和模型误差，所以这是有实测背景的压力测试，**不是已证明不变的恒星，也不能给出真实星误报率**。交叉拟合仅防止每个点直接参与自己的模板拟合，不保证训练、测试噪声相互独立。

预定 34 个案例：2 种背景 ×（2 种信号 × 4 档幅度 × 2 个初始相位 + 1 个零注入）。平滑正弦周期 0.731 天，食形周期 1.371 天；两个初始相位为 0.13、0.57，跨时段使用同一个起点。幅度为源文件中位通量的峰谷全差：0.1%、0.3%、1%、3%；正弦半振幅因此是一半。食形主谷最大深度等于全差，次谷为其 45%，每个谷持续一圈的 8%。有限观测采样和 10 分钟分箱会改变实际测得的峰谷差。

同一人工信号加到两产品已处理的通量中；不经过像素提取或 TESS 的 PDC 校正，因此不能检验这些上游步骤会保留、压低或制造哪些变化。保留辅助通道只是压力诊断，人工信号并未使质心/背景发生物理自洽的变化，也没有模拟拥挤稀释。

检测使用冻结 v4。原星周期只用于构造残差，注入周期只用于生成信号和事后评分，均不传入检测函数。先保存全量未评分预测，再检查：最终周期正确、半周期、双周期、其他周期、弃选，以及两时段是否都有与注入周期一致的合格候选。正确容差为 1%，沿用旧标准；零注入检出一律记为残差背景中的候选，不算真实安静星误报。不同幅度、相位、产品、时段不算不同恒星；共用背景的 32 个注入结果相关，不计算假定独立的准确率置信区间。

不根据本轮结果调整 v4、注入幅度、残差模型或背景星。任何失败都保留。仅覆盖两个周期和两种形状，不能用某档全部成功宣称通用灵敏度下限。

从项目根目录运行：

```sh
OPENBLAS_NUM_THREADS=1 repo/.venv/bin/python repo/benchmarks/run_empirical_injection.py prepare
OPENBLAS_NUM_THREADS=1 repo/.venv/bin/python repo/benchmarks/run_empirical_injection.py evaluate --workers 2
```

`inputs/` 中的压缩 FITS 是人工修改文件，带 `SYNTHET=T`，绝不能当原始观测引用。原始 FITS、来源、哈希保留在 `protocol.json`。`residuals/` 保存扣除模板与剩余量，`input-manifest.json` 保存各组拟合参数与全部输入哈希。所有旧实验的保全哈希见 `preserved-inputs.json`。
