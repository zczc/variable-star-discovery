# 首次使用的 6 颗真实已知变星

[结果报告](evaluation/index.html) · [输入清单](input-manifest.json) · [身份核对](identity-audit.json) · [选择方案](../independent-pilot-protocol-v01.json)

预先固定 W UMa、RZ Cas、U Sge、RT Aur、SZ Lyn、RS Boo 六个名字，从 VSX 精确名称取得身份、坐标和参考周期，再匹配 10 角秒内最近 TIC。实际位置差约 0.03–0.07 角秒。TIC 与所有此前运行清单、已知对照清单去重，不按后续分析效果选星。

每颗下载最早和最晚可用的非 fast SPOC 光变，共 12 个 FITS。文件、原始 VSX/TIC 响应、MAST 观测列表、来源和校验值均纳入 Git。原始观测没有在选样阶段做光变分析。

RT Aur 较新观测是实际 FITS 头部给出的 Sector 1751，2026-01-15 至 2026-01-22，只有约 7 天。遵守冻结规则保留，不用更长或更容易通过的观测替换。较早时段也未通过预测要求，不能把失败全归因于短观测。

## 结果与独立性的范围

最终算法于 `97efb49` 固定后才分析这些光变；随后没有根据它们的结果调参。6 颗中 5 颗检出重复信号，最终周期 3 颗正确、1 颗双周期错误、1 颗保留歧义、1 颗未通过。所有分母、未定和错误都保留。

这是小规模、按名字挑选的正例测试。它们没有参与此前调试，但不代表随机总体抽样。真实安静星反例数为 0，不能测真实误报率。若后续拿这些对象改算法，它们就成为开发样本；下一轮需另外冻结测试对象。

## 复现

```bash
repo/.venv/bin/python repo/benchmarks/evaluate_v2.py --mode independent-pilot --output repo/benchmarks/v2-pilot-rerun
```

在仓库根目录运行。复跑同一组星不增加独立样本数。输入都已随仓库保存，不需要重新访问外部目录；若要研究目录变更，应另存新的身份快照。

`acquire_independent_pilot.py` 保留原获取方法，并拒绝覆盖现有目录。原始查询由缓存复用；要建立下一轮样本，应制定新的协议和路径，而不是删改本轮文件。
