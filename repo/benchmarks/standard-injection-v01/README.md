# 标准星原始测光注入 v01

本实验在 G 191-B2B、GD 71、GD 153 的既有原始 SPOC 测光上直接加入人工信号。每星使用上一轮的两个时段，不拟合或扣除原星周期，不打乱、缩放或替换噪声。它们的未注入检测结果已经看过，因此这轮是有条件的恢复试验，不是新的独立真实变星验证。

在构造和运行前固定：3 颗背景星 × 2 个周期（0.731、2.413 天）× 3 种形状 × 4 档峰谷全幅度（0.1%、0.3%、1%、3%）× 2 个初始相位（0.13、0.57）= 144 个非零注入；每星另有 1 个零注入，共 147 个案例。三种形状为平滑正弦、每个谷持续一圈 8% 的深浅食、每个谷持续一圈 2% 的窄食。次谷深度固定为主谷的 45%；谷形采用平滑余弦函数，不代表完整双星物理模型。

幅度指连续瞬时信号的峰谷全差，占各产品原始可用通量中位数的比例；正弦的半振幅为此数的一半。两个时段共用第一段的 BTJD 时间原点和相位。用 FITS 的 TIMEDEL 作为矩形平均窗口，解析积分人工信号，近似单次采样对短暂变化的平滑；它不是 TESS 每次相机曝光的精细模型。分析中的 10 分钟分箱照旧，所以实际采样/分箱后的幅度还会变小。相同的相对信号分别加入 SAP/PDCSAP，保留误差和辅助列；不重新运行像素提取或 PDC，不调整光子噪声，也不模拟拥挤稀释与质心变化。

使用已冻结的 v4，检测函数只接受人工 FITS 路径和案例标识，不收到注入真值或标准星标签。先保存所有未评分预测，再按原来的 1% 周期容差统计最终选对、半周期、双周期、其他周期、弃选和运行失败。另保留两个时段都出现真值附近合格候选的比例；需同一种产品在两段中都支持。零注入记录本次程序输出，不作为已证明的真阴性。

所有同星注入共用实测背景，不能把 144 次当成独立恒星样本；不据此计算总体准确率、误报率、发现概率或独立二项置信区间。标准星的外部标签仍有波段、精度和时间覆盖限制，正式 TESS 安静星分母仍为 0。不得根据本轮结果调整阈值、样本、幅度或周期后把新分数当作独立验证。`independent-pilot-v02` 保持封存。

## 复现

原始 6 份 FITS 和下载凭据已在公开仓库。`protocol.json` 冻结源文件、信号参数、时间原点与代码哈希；`input-manifest.json` 保存每份人工文件的参数和哈希。大量重复的人工 FITS 放在忽略的本地缓存 `repo/data/standard-injection-v01/`，由已公开的原始数据和代码确定性重建；本轮不新增原始望远镜观测。报告、预测、评分和全部构造信息纳入仓库。

从项目根目录执行：

```sh
# 第一次准备；已经有 input-manifest.json 时不覆盖。
OPENBLAS_NUM_THREADS=1 repo/.venv/bin/python repo/benchmarks/run_standard_injection.py prepare
# 克隆仓库后，按已公布的输入清单重建并校验人工文件。
OPENBLAS_NUM_THREADS=1 repo/.venv/bin/python repo/benchmarks/run_standard_injection.py rebuild --case all
# 新运行目录中执行；已有完成的预测不覆盖。
OPENBLAS_NUM_THREADS=1 repo/.venv/bin/python repo/benchmarks/run_standard_injection.py evaluate --workers 2
```

`rebuild --case <案例 ID>` 可以只重建一个案例；`--case all` 重建全部。人工 FITS 带 `SYNTHET=T`，不能作为某颗星真实变化的证据。新的实验要另设版本/目录，既有结果不覆盖。
