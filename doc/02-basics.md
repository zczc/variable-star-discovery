# 从零认识变星

## 我们观察的是什么

恒星是会自己发光的天体，太阳就是一颗恒星。天文学家已经记录了大量恒星的位置和亮度，但知道一颗星在哪里，并不意味着已经研究过它随时间变化的全部行为。

把同一颗星在不同时间的亮度依次画出来，就是光变曲线。横轴是时间，纵轴是亮度。如果变化超过测量误差，并且确实来自天体或天体系统，就可能是变星。

变星不一定有稳定周期。有些规律地变亮变暗，有些只有近似周期，有些会突然爆发。本项目先找周期清楚、已有多次观测可验证的对象，方便初学者建立证据。

## 为什么会变亮变暗

| 原因 | 可以怎样理解 | 常见光变特征 |
|---|---|---|
| 恒星脉动 | 恒星的大小、温度发生变化 | 亮度周期性起伏，有时包含多个周期 |
| 双星相互遮挡 | 两颗星绕转，其中一颗从另一颗前面经过 | 周期性的亮度下降，可能有深浅不同的两次下降 |
| 自转和星斑 | 表面不同区域随自转转到我们面前 | 近似周期起伏，形状和幅度可能变化 |
| 耀斑或其他爆发 | 恒星或系统短时间释放较多能量 | 突然增亮，未必规律重复 |

前几类曲线有时很相似。看到周期只能说明存在重复信号，不能仅凭一张图确定物理原因。

## 发现恒星、变星和新星

| 说法 | 含义 |
|---|---|
| 发现一颗此前未记录的恒星 | 首次识别这个天体本身；不是本项目的主要目标 |
| 发现一颗新变星 | 这颗星可能早有编号，但首次发现或可靠报告它的变光性质 |
| 发现经典新星 | 发现一次特定类型的爆发，通常与双星系统中的白矮星表面热核爆发有关 |

“新星”是天文学中的专门术语，不是刚诞生的恒星，也不是“新发现的变星”的简称。经典新星属于爆发性变星现象；超新星又是不同的物理事件。

例如，一颗已有 TIC 编号的星一直被当成普通恒星。如果我们首次可靠证明它每隔一段时间就发生亮度变化，这项新认识可以构成变星发现。

## 周期、幅度和相位

假设一颗星每隔 2 天重复一次亮度变化，它的周期就是 2 天。每次变化有多大，称为变幅。周期和变幅是最基本的描述，但不同测量方法、波段和观测时段会影响结果。

把每个周期从头到尾都缩放到 0 到 1，再把许多周期叠起来，就是相位折叠。如果周期准确而且变化较稳定，散点会重复落在相近的位置。折叠时还要选一个起始时刻，通常称为参考历元。

食双星的一圈轨道可能出现两次相似的变暗。算法有时把半圈当成一个周期，所以必须同时检查候选周期的两倍、二分之一及其他可能的混叠。

观测间隔、数据缺口和仪器运动也会制造周期特征。漂亮的相位图本身不足以证明发现。

## 亮度的单位

望远镜数据常给出通量，可以理解为仪器收到的光。相对通量把亮度除以一个参考值，便于观察百分之几或千分之几的变化。

天文学还使用星等：数值越小，天体越亮，而且刻度是对数的。小变幅时，1 mmag 约对应 0.092% 的通量变化。不同波段的星等不能不加处理地混在一起比较。

前期代码中的 `phase_amplitude_pct` 是相位分箱后的一种相对通量幅度估计，不直接等同于标准目录的最大、最小星等。

## TESS、MAST 和目录各自做什么

- **TESS**：持续测量许多恒星的亮度，主要任务包括寻找系外行星，也产生适合研究变星的数据。一个观测区通常覆盖约 27 天，部分恒星在多个观测区中反复出现。
- **MAST**：公开天文数据档案，存放 TESS 等项目的观测产品。
- **TIC**：TESS 目标目录。TIC 编号用于识别对象，不表示这颗星已被认定为变星。
- **VSX**：AAVSO 的变星索引，用于检索变星资料和提交新条目。
- **SIMBAD、VizieR、ADS**：分别帮助查对象资料、研究目录和论文。它们的内容及更新节奏不同，需要结合使用。

TESS 的一个像素约覆盖 21 角秒，可能混进多颗恒星的光。像素数据能帮助检查变化究竟来自哪颗星；只看下载好的光变曲线容易受到邻星干扰。

## 分析光变还能得到什么

除了识别新变星，还可以修正已知对象的周期、研究脉动和自转、寻找食双星、发现耀斑、观察周期或形状随时间的变化。少数对象可能提供更罕见的物理线索，但这通常需要更多观测和专业分析。

LLM 可以帮助写代码、组织检索和解释结果。周期计算、图表、坐标匹配及最终判断必须以实际数据和可检查的证据为依据。
