# 这份真实观测里的词是什么意思

本例是 TIC 9473243。可以先把整件事理解成：太空望远镜反复测量同一个光点，我们拿到一张“时间—亮度”表，再检查它是否重复变化、多久重复一次。

## 谁测的，测的是谁

| 页面上的词 | 日常解释 |
|---|---|
| TESS | 取得这份观测的太空望远镜。它会连续测量许多恒星的亮度。 |
| TIC 9473243 | 这个观测对象在 TESS 目标目录里的编号，类似检索用的档案号。编号本身没有给出是否变光的答案。 |
| 食双星 | 两颗互相绕转、从我们的方向看会彼此遮挡的恒星。本例测到的是它们合起来的光。 |
| Sector 25、Sector 79 | TESS 两批观测的编号，分别对应一片天空及一段观测时间。本例两批都看到了同一个目标，可以用不同时期的记录互相核对。 |
| MAST | 存放 TESS 等项目公开观测的数据档案网站。 |

“真实观测”表示这里用的时间和亮度来自望远镜测量，不是为了演示而编造的曲线。质量筛选、取平均和改坐标是我们对真实测量的处理，仍要说明怎样处理。

## 两张图到底画了什么

**光变曲线**就是亮度随时间变化的图。左图横轴写“天”，表示从这一段记录开始，已经过去多久；纵轴表示相对于参照亮度，多了或少了多少光。每个点是约 10 分钟内若干次有效测量的平均值。

**通量**可以先理解为仪器收到的光的多少。它不直接等于恒星向所有方向发出的总能量；距离、波段、遮挡和仪器等都会影响我们收到的光。

**相对亮度变化**是把这些数换成便于比较的百分比。本页先将当前所选测量的亮度从小到大排列，取中间的数作为参照，这叫中位数。然后计算每次测量比参照多或少了多少。

用参照值把亮度换成这种相对表示，属于常说的**归一化**。它没有增加新的测量，也不会把仪器误差自动消除。切换数据方案后，参照值可能不同。

| 图上的数 | 含义 |
|---|---|
| 0% | 与参照亮度相同，仍然有光 |
| −20% | 比参照少 20%，还收到参照值 80% 的光 |
| +10% | 比参照多 10%，收到参照值 110% 的光 |

**深谷、浅谷、食**：图上向下凹就是收到的光减少了。食双星里，一颗挡住另一颗会产生一次“食”，在图上可能形成一个谷；两次食不一定同样深。没有检查来源前，单个谷本身不能证明发生了遮挡。

**幅度或变幅**表示变化有多大。不同软件可能用最大减最小、分位数差或模型拟合等不同定义。前面筛选报告的相对通量幅度不是正式标定星等，也不是精确的遮挡比例。

**星等**是另一套亮度刻度，数值越小越亮，并且使用对数。本练习图使用的是相对通量百分比，你不需要先学会星等换算。

## 周期、相位和折叠

**周期**是完整重复一次需要的时间。本页用“天”作单位；1 天是 24 小时，0.5 天是 12 小时。对于食双星，通常报告的是两颗星转完一整圈的轨道周期。一圈可以有两次变暗。

**相位**表示进行到这一轮的哪个位置，从 0 到 1。这里是经过时间占整个周期的比例，不是直接测到了恒星在轨道上的角度。

假设我们正在尝试“2 天重复一次”，并选择某个时刻作为开始：

| 从起点过去多久 | 处于这一轮的哪里 |
|---|---|
| 0 天 | 刚开始，相位 0 |
| 0.5 天 | 进行到四分之一，相位 0.25 |
| 1 天 | 进行到一半，相位 0.5 |
| 1.5 天 | 进行到四分之三，相位 0.75 |
| 2 天 | 下一轮开始，又记为相位 0 |
| 2.5 天 | 下一轮的四分之一，又记为相位 0.25 |

**相位折叠**就是把相同相位的测量放在相近的横坐标位置。右图重新摆放了左图中的点。不同轮若重复得好，同类变化会叠在一起；试错周期，或把深浅两次食当成同一类事件，点就可能散开或分成两层。漂亮的形状仍需排除其他解释。

**相位零点**是你规定一轮从哪里开始。本页每个观测时段分别用自己的起点，因此另一时段的谷在横轴上换位置，并不自动说明周期改变了。正式比较跨年是否精确重复，需要共同参考时刻、足够准确的周期和不确定性分析。

**半周期、倍周期**是候选周期的一半或两倍。食双星的两次下降容易让软件选到半周期，但也不能对所有对象一律乘二。对于偏心轨道，两次食的间隔还可能不等于半个周期。

## LS、BLS、周期图和峰

**LS（Lomb–Scargle）**是尝试用类似波浪的重复成分解释数据的方法。你可以把按钮理解成“试一试波浪搜索选出的周期”。它不负责证明对象一定是某种恒星，也会遇到半周期等误判。

**BLS（Box Least Squares）**尝试寻找反复出现的变暗片段，常用于研究食或凌星这类亮度下降。它同样可能选错。本例的辅助 BLS 搜索只尝试有限的一组下降持续时间。

**候选周期**就是值得进一步检查的周期猜测。按钮把它填进输入框，然后按这个周期画右图，没有替你完成最终判断。

**周期图、峰、LS power**：软件尝试很多周期后，把相应的评分画出来。高峰表示某个试验周期得分较高。图上的 power 是统计量，不是恒星释放的功率，也不是“有百分之多少把握”。不同方法的评分不能直接混为一谈。

**搜索范围 0.05–8 天**是这次让软件尝试的范围，不代表所有恒星的周期都在这里。**搜索边界**就是两端；最高分刚好卡在边界时，有可能只是更长或更短变化的一个片段，不能直接当成准确周期。

**混叠、假峰**表示采样间隔、缺口、信号形状等可能让不同周期看起来都像合理答案。实际测量没有连续覆盖每一瞬间，需要检查这种歧义。显示很多小数位也不等于周期精确到了那些位。

## 数据处理选项

| 名词 | 做了什么，为什么要看 |
|---|---|
| 测光 | 从图像或探测器读数中估计收到多少光。 |
| 孔径 | 在图像上选定、用来统计目标光的区域，可以不是圆形；这里不是望远镜镜头的口径。 |
| SAP | 统计选定区域内的光，并进行背景等基础处理后的测光结果。 |
| PDCSAP | 在 SAP 基础上进一步减少部分仪器造成的变化。它也可能影响真实变化，因此要比较两种版本。 |
| 系统效应 | 例如指向移动或背景光变化，造成许多点或多颗星出现有关联的测量变化。 |
| QUALITY、质量标记 | 数据提供方给测量附上的质量警告。0 表示该字段没有设置警告位，不是质量得零分；也不保证完全没有问题。 |
| 有效点 | 在本练习里，至少要求时间、亮度、误差能使用，且误差为正；再按所选方案决定是否排除带质量标记的点。 |
| 分箱、10 分钟平均 | 把约 10 分钟内的测量合并成一个平均点。它会减少点数，也可能削弱很短的真实变化。 |
| 误差、不确定性 | 每个亮度数字不是无限准确的。页面数值由仪器给出的误差估算，不包含所有背景、处理和相关噪声影响。 |
| 噪声 | 测量中不属于我们所研究的天体变化的波动，可以近似随机，也可以随时间有关联。 |

## 信号究竟来自哪里

**像素**是图像中的小格子。TESS 一格覆盖的天空可能包含不止一颗星；只看合起来的亮度，容易混入附近天体的变化。

**邻星污染**表示附近恒星的光混进了我们给目标提取的记录里。不是恒星被某种物质污染，而是把别人的变化误算到了目标身上。

**背景**是目标之外落在测量区域里的光等成分。**质心**可以理解为图像亮斑的加权中心位置。背景或中心位置随时间变化，能为仪器问题、混光或来源判断提供线索，但单项相关性不能独自定案。

**来源定位**就是检查究竟哪个位置的光在变。本例尚未完成自己的像素来源复核，不能只因周期符合已有研究就宣称完成了这一步。

## 保存文件和查目录时才会遇到的词

| 名词 | 用途 |
|---|---|
| CSV | 一种保存表格的文本格式。 |
| FITS | 天文学常用的数据文件格式，可保存图像、测量表及观测说明。 |
| 校验值、SHA-256 | 文件的数字指纹，用于检查文件是否相同或发生损坏；不用于判断科学结论是否正确。 |
| 波段 | 仪器主要测量光的哪一段波长范围，可以粗略理解成选了哪一段颜色范围，但有些范围超出肉眼可见颜色。 |
| BJD、HJD | 将观测时刻按不同空间参考位置修正的时间表示；前者参考太阳系质心，后者参考太阳中心，不能只改列名互换。 |
| TDB | 本例采用的时间刻度约定，不是地理时区。 |
| BTJD | 在本例里是 BJD_TDB 减去 2457000 天，让时间数字短一些。页面画图又减去了本段起点，便于读经过多少天。 |
| VSX | 用于查询已有变星资料的索引。 |
| AAVSO | 维护 VSX 等资源的美国变星观测者协会。 |
| 候选、确认、新发现 | 候选表示值得复核；确认需要充分证据；新发现还要核实此前是否有人报告。三者不能当成同一个状态。 |

第一遍先保留默认数据处理。看懂“时间、亮度、周期、相位”后，再回来看处理选项；文件格式和正式提交时的时间换算可以放在后面。
