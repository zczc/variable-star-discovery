# 项目目标与当前状态

更新日期：2026-11-10。

## 想完成什么

从 MAST 等公开档案中的 TESS 观测开始，寻找亮度有可重复周期、但此前未被报告为变星的恒星。优先选择已有多个观测时段、可以在线交叉验证的目标。

用户希望亲自参与一项有实际发现机会的业余研究，在证据充分并符合目录规则时，被记录为发现者。最初目标是一颗普通的新变星，不以罕见天体、重大物理发现或自行命名恒星为前提。

用户是天文学初学者。研究过程中应解释每个步骤在排除什么问题，以及证据能支持到什么程度。

## 怎样才算有结果

| 阶段 | 可以声称什么 | 还不能声称什么 |
|---|---|---|
| 找到周期候选 | 算法在这份光变数据中找到重复信号 | 信号一定来自目标恒星 |
| 复核变光与来源 | 多时段支持变光，现有检查支持目标是信号来源 | 此前无人发现 |
| 完成目录和文献查重 | 在记录下来的检索范围内未找到先前报告 | 绝对不存在遗漏 |
| 整理发现报告 | 证据和方法可供他人检查 | 已获目录认可或发现者登记 |
| 目录接受或论文发表 | 按实际接受内容报告成果和归属 | 自动获得正式命名权或重大科学认可 |

本项目近期采用的工作标准是：在多个独立观测时段中验证周期，排查仪器和邻星干扰，完成有记录的目录及文献检索，再准备提交资料。这是项目的选择策略，不是对所有变星或 VSX 条目的统一要求。

## 已经确定的安排

- 使用公开数据起步，暂不购买望远镜，也不申请观测时间。
- 文档放在 `doc/`；代码、实验和发现资料放在 `repo/`。
- 用户于 2026-11-10 要求创建私有 GitHub 仓库，把整个工作空间纳入版本控制，包括 `doc/`、`repo/` 和当前观测数据。
- 此次明确保存本项目材料，不修改 `just_chat` 的主题索引或其他主题记录。

## 当前状态

已阅读三项近期研究，并核对 VSX 官方提交指南。前期试验选取 33 个目标，4 个存在近位置 VSX 条目，其余 29 个完成初筛。3 个对象进一步比较了多个观测时段，2 个检查了像素中的信号位置。

目前没有完成全部验证的新变星，也未提交 VSX。前期样本不是为测量发现率设计的，不能从中估计用户的成功概率。

下一轮约 1,000 个目标的筛选是讨论中的建议，尚未开始。应先整理样本选择方法、排除原因和查重记录，再扩大规模。
